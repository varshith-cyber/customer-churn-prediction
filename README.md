# Customer Churn Prediction & Retention Analytics

An end-to-end data science project that analyzes customer churn, identifies churn patterns, trains a classification model, and ranks customers by predicted churn risk.

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Tech
Python, Pandas, Scikit-learn, Plotly, Streamlit

## Resume skills
EDA, feature engineering, classification, model evaluation, churn analysis, risk scoring, data visualization, business insights.
